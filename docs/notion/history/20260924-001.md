# 현재 설명과 변경 기록 양식 등록

## 작업 목적
프로그램마다 고정 노션 페이지 하나에서 현재 설명과 이후 변경 기록을 볼 수 있게 문서 기준을 등록합니다.

## 변경 내용
현재 상태 설명, 불변 이력 양식, 공용 노션 게시 연결을 추가합니다. 초기 등록 이전의 모든 Git 커밋을 수리 이력으로 추측해 복원하지 않습니다.

## 변경 위치
`docs/notion/project.json`, `current.md`, `history/`, `.github/workflows/notion-documentation.yml`, 기존 작업 안내에 문서 규칙 연결을 추가합니다.

## 확인 결과
기준 버전의 문서와 파일 구성을 읽었습니다. 앱 동작 시험은 수행하지 않았습니다. 노션 첫 게시의 성공 여부는 해당 Actions 실행 결과로 확인합니다.

## 적용 상태
문서 자동화 등록입니다. 앱 출시, 매장 교체, Arduino 업로드를 수행한 작업이 아닙니다.

## 남은 작업
필수 환경 설정, 이 포크의 사용자 수정 범위, 콘텐츠별 실제 요약 결과를 확인해야 합니다.
